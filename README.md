# IELTS Reading Trainer

Single-page IELTS Reading trainer (Collins-based units, 3 full 40-question tests, spaced repetition, mock exam, progress backup). No build step.

Files (flat, no folders): `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`.

## Run
Open `index.html`, or host on GitHub Pages: Settings → Pages → Deploy from branch → `main` / root. PWA offline mode needs https (Pages provides it).
