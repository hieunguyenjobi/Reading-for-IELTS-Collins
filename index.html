⚙️ Cấu hình Supabase

Lấy 2 giá trị này từ Supabase → Project Settings → API. Chỉ cần điền 1 lần, app sẽ nhớ trên trình duyệt này.

Bước tiếp theo sau khi Lưu:

  1. Vào Supabase → SQL Editor → chạy đoạn SQL dưới đây (tạo bảng + RLS, mỗi user chỉ thấy dữ liệu của mình)
    Xem SQL 
    create table if not exists public.user_progress (
  user_id uuid primary key references auth.users(id) on delete cascade,
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);
alter table public.user_progress enable row level security;
drop policy if exists "own select" on public.user_progress;
create policy "own select" on public.user_progress for select using (auth.uid() = user_id);
drop policy if exists "own insert" on public.user_progress;
create policy "own insert" on public.user_progress for insert with check (auth.uid() = user_id);
drop policy if exists "own update" on public.user_progress;
create policy "own update" on public.user_progress for update using (auth.uid() = user_id) with check (auth.uid() = user_id);
drop policy if exists "own delete" on public.user_progress;
create policy "own delete" on public.user_progress for delete using (auth.uid() = user_id);
  2. Authentication → Providers → Email → bật Email
  3. Bấm Đăng nhập trên app và nhập email

Tài khoản học

Chưa cấu hình Supabase. Mở menu ⋯ → Cấu hình đồng bộ, dán Project URL và anon key, rồi Lưu.

Unit 1 • Matching Headings

Golden Tip: Skim-read — only the first sentence of short paragraphs, and first + last sentences of long paragraphs before looking at the heading list.

Unit 2 • Completing Tables

Always check word limit (NO MORE THAN THREE WORDS). Numbers & hyphenated words count as 1 word. Scan for capitals, numbers, currency symbols.

Đăng nhập bằng email → tiến độ được lưu trên cloud. Học trên điện thoại hoặc máy tính khác vẫn giữ nguyên điểm và đáp án.
